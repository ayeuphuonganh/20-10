WEB LỜI CHÚC 20/10 - GỬI VỢ 💗

CÓ GÌ TRONG WEB?
- 3 lời chúc theo đúng nội dung đã yêu cầu (đã bỏ lời chúc thứ 4).
- Lời chúc tự động chuyển sau khoảng 6,5 giây; có thể bấm nút ♡ / ✦ để chuyển thủ công.
- Chữ hồng neon và chuyển cảnh mờ dần, hiện dần.
- Nền sao nhấp nháy, sao băng, cánh hoa bay, hoa đung đưa, đom đóm và bướm chuyển động.
- Nút bật/tắt nhạc ở góc trên bên phải.

CÁCH THÊM NHẠC:
1. Thêm một file MP3 mà bạn có quyền sử dụng vào cùng thư mục với index.html.
2. Đặt tên chính xác là: nhacnen.mp3
3. Tải cả index.html và nhacnen.mp3 lên cùng thư mục gốc của GitHub repository.
4. Mở web và bấm nút “♫ Bật nhạc”. Trình duyệt điện thoại thường yêu cầu bấm nút trước khi phát.

LƯU Ý:
- ZIP không kèm bài “Chờ Chút” vì không thể tự lấy và phân phối bản nhạc có bản quyền từ nguồn bất kỳ. Hãy dùng file bạn được phép sử dụng hoặc nguồn phát được cấp phép.
- Nếu chưa có nhacnen.mp3, toàn bộ hiệu ứng và lời chúc vẫn hoạt động bình thường.
- Để xuất bản bằng GitHub Pages: Repository > Settings > Pages > Deploy from a branch > main > /(root) > Save.
