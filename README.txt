NHẠC ĐÃ ĐƯỢC NỐI VÀO WEB QUA FILE nhacnen.mp3

Lưu ý: file âm thanh bài hát chưa được bao gồm vì bạn chưa gửi MP3. Để nhạc chạy, tải file MP3 mà bạn có quyền sử dụng lên cùng thư mục với index.html và đặt tên chính xác nhacnen.mp3. Người xem bấm nút nhạc để phát.

Đăng GitHub Pages: tải index.html và nhacnen.mp3 lên repository; vào Settings > Pages > Deploy from a branch > main > /(root) > Save.
