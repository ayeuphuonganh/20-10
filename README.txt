WEB LỜI CHÚC 20/10 — PHONG CÁCH CỔ TÍCH

1. Giải nén ZIP và mở index.html trong trình duyệt để thử.
2. Muốn có nhạc, đặt file âm thanh bạn có quyền sử dụng tên nhacnen.mp3 cạnh index.html.
3. Khi đưa lên GitHub Pages, tải index.html (và nhacnen.mp3 nếu có) lên repository rồi bật Settings > Pages.

Mật khẩu: 07062012
Lưu ý: mật khẩu được kiểm tra ở phía trình duyệt, chỉ là màn hình mở đầu vui vẻ, không bảo vệ nội dung bí mật thực sự. Trình duyệt thường yêu cầu chạm nút Bật nhạc trước khi phát.
